# A.4 QUADRATIC FORMS


Let An×n be a symmetric matrix, and X be an n-element vector. The function f(X) defined as

- f(X) = XTAX

is called a quadratic form. Since XT is of order 1 × n and A is n × n and X is n ×1, the product

- \[x<sub>1</sub>,x<sub>2</sub>,…,x<sub>n</sub>\]

exists and can be computed. Clearly, f(X) is a scalar value, and can be written as

- f(X) = aijxixj

Thus, f(X) is a sum of quadratic terms, and hence the name "quadratic form."

In this context, the matrix A has one of the following characteristics:

Positive definite If f(X) > 0 for all X ≠ 0

Positive semidefinite If f(X) ≥ 0 for all X and there exists an X ≠ 0 for which f(X) = 0

Negative definite If f(X) < 0 for all X ≠ 0

Negative semidefinite If f(X) ≤ 0 for all X and there exists an X ≠ 0 for which f(X) = 0

Indefinite If none of the above
